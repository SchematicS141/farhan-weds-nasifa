FARHAN WEDS NASIFA — VERCEL PROJECT

This folder is a complete Vite + React project containing your uploaded wedding invitation.

To run locally:
1. Install Node.js (LTS) from https://nodejs.org/
2. Open this folder in VS Code.
3. Open Terminal > New Terminal.
4. Run: npm install
5. Run: npm run dev

To deploy:
1. Upload the contents of this folder to a GitHub repository named farhan-weds-nasifa.
2. In Vercel, choose Add New > Project and import that GitHub repository.
3. Framework Preset: Vite; Build Command: npm run build; Output Directory: dist.
4. Set Project Name to farhan-weds-nasifa (if available), then Deploy.

The project already includes React, Framer Motion, Lucide React and Tailwind CSS dependencies.
